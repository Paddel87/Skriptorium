# Salzlicht

- Gebundenes Salz, das auf den Befehl „leuchte" kaltes, bläuliches Licht gibt. Wärmt nicht, brennt nicht, raucht nicht.
- Einzige erlaubte Bindung ohne eigene Genehmigung: Die Stillen Schwestern halten eine alte Sammelgenehmigung für die Lampen des Archivs.
- Eine Salzlampe leuchtet etwa so hell wie eine Kerze.
